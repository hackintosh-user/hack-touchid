Touch ID for Hackintosh

Fingerprint authentication for macOS on unsupported hardware. Unlock with a real fingerprint sensor instead of typing your password.

Get startedDocumentationGitHub

What is it?

HTID is a fingerprint authentication daemon for macOS on Hackintosh hardware. It ports the USB capture protocol of supported fingerprint sensors to native C, matches swipes with NIST's NBIS suite, and types your password into the macOS prompt when your finger matches. It is not a kernel extension and not a libfprint port.

Built for laptops that shipped with a fingerprint sensor but have no native macOS driver.

Features

Lock screenUnlock with a fingerprint swipe.
Authentication promptsSystem Settings padlock, Finder, Passwords.app and Keychain Access consent prompts.
Multi-finger enrollmentEnroll several fingers, best match wins.
Fully nativeNo kernel extension and no libfprint at runtime. A small background daemon.
Encrypted storageTemplates and the stored password live on a dedicated encrypted APFS volume.
Menu bar appOptional app to enable, disable or restart the daemon, with notifications when it is ready to swipe. On macOS Tahoe only, it also has a Swipe to Lock toggle.
Settings paneManage fingerprints, the match threshold and updates from System Settings, no terminal needed.
Swipe to Lock (Tahoe only)One swipe on the sensor locks the screen. VFS5011 on macOS 26 Tahoe only. Turn it on from the menu bar app.
Touch to Lock (Tahoe only)A touch from an enrolled finger locks the screen. Synaptics Metallica MIS on macOS 26 Tahoe only, confirmed on 06cb:009a.
Red light on a wrong fingerThe VFS5011 sensor light flashes red when the finger is not recognized, then goes back to the ready light.

Settings pane

HTID adds its own pane to System Settings, so you can manage fingerprints without the terminal. Install it from the client menu with [I] Install Preference Pane (System Settings). It also has Sensor and About tabs.

Supported macOS

VersionStatus
macOS 15 Sequoia and laterRecommended
macOS 14 SonomaSupported (minimum)
macOS 13 Ventura and olderNo support. It may work, but you are on your own.

OpenCore v1.0.6 or later is required for support. Release or Debug builds are both fine. Older versions may work but are not supported.
